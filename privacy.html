Privacy policy

ourMusic bot is a personal Discord bot used only by its owner.

  • With the owner's permission it reads, read-only, the owner's YouTube playlists and liked videos through the YouTube Data API, so it can play them in Discord.
  • The sign-in token is stored only on the owner's own computer. No data is sold, shared with third parties, or used for advertising.
  • Access can be removed at any time at myaccount.google.com/permissions.

Use of information received from Google APIs adheres to the Google API Services User Data Policy.
